# Changelog

## 0.1.0 — 2026-11-18

- Initial beta release for middle- and high-school EBS DANCHOO+.
- Added manual print-area selection.
- Added A4, A5, and Letter paper sizes with portrait and landscape orientation.
- Added one- and two-column layouts, font-size and line-height controls, and margin presets.
- Added print-only isolation and browser print-dialog support.
