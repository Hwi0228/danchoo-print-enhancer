# DANCHOO Print Enhancer

중학·고등 EBS DANCHOO+의 **기존 시험지 생성 및 인쇄 기능을 유지하면서**, 문항 단위 페이지 분할을 보정하는 Tampermonkey 사용자 스크립트입니다.

> 비공식 개인용 도구입니다. EBS와 제휴·승인된 프로젝트가 아닙니다.

## v0.2.0 변경 사항

v0.1.0은 사용자가 인쇄 영역을 다시 선택해 별도의 브라우저 인쇄를 실행하는 방식이었습니다. 실제 DANCHOO+의 출력물은 이미 EBS가 A4 2단 시험지를 생성하고 자체 인쇄 미리보기와 프린터 설정을 제공하므로, 이 방식은 기존 워크플로와 맞지 않았습니다.

v0.2.0은 다음 URL에서만 실행되며 EBS의 인쇄 기능을 대체하지 않습니다.

- `https://ai-plus.ebs.co.kr/mid/xip/solvePaper.ebs`

PDF 샘플에서 확인한 개선 목표는 문항·보기·그림이 다음 단이나 다음 페이지로 갈라지는 현상을 줄이는 것입니다. 새 버전은 다음을 수행합니다.

- 현재 문서와 접근 가능한 동일 출처 iframe에서 문항 블록을 자동 감지
- 문항 블록에 `break-inside: avoid` / `page-break-inside: avoid` 적용
- 문항 제목을 다음 내용과 가능한 한 함께 유지
- 그림, 표, 그래프, 인용·보기 상자 등이 중간에서 분리되지 않도록 보정
- 문단의 고아 줄·과부족 줄을 줄이기 위한 `orphans` / `widows` 설정
- EBS의 기존 미리보기·인쇄 버튼을 그대로 사용

## 설치

1. Chrome 또는 Edge에 Tampermonkey를 설치합니다.
2. [`danchoo-print-enhancer.user.js`](danchoo-print-enhancer.user.js)를 엽니다.
3. Tampermonkey 설치 화면에서 스크립트를 추가합니다.
4. EBS 중학·고등 DANCHOO+에서 시험지 풀이 화면을 엽니다.
5. 화면 오른쪽 아래 도구에서 **문항 묶음 보정 켜짐** 및 감지 문항 수를 확인합니다.
6. EBS의 기존 인쇄 미리보기와 **인쇄** 버튼을 그대로 사용합니다.

보정 도구는 인쇄 설정을 새로 만들지 않습니다. 용지, 매수, 레이아웃, 컬러, 프린터 대상은 EBS 화면의 기존 설정을 사용합니다.

## 동작 범위

- 지정한 `solvePaper.ebs` 경로에서만 실행합니다.
- 현재 페이지와 동일 출처로 접근 가능한 iframe의 DOM에 인쇄용 CSS를 적용합니다.
- 문항 번호로 시작하는 블록을 휴리스틱으로 감지합니다. 감지 결과는 도구에 표시됩니다.
- 보정은 언제든 켜고 끌 수 있으며 설정은 브라우저 로컬 저장소에 저장됩니다.
- EBS 계정·비밀번호·쿠키·문항 API를 읽거나 전송하지 않습니다.
- 외부 서버 통신, 문항 다운로드, 별도 PDF 재생성은 하지 않습니다.
- EBS 원본 문항 텍스트·이미지·정답 데이터는 변경하지 않습니다.

## 알려진 제한

- PDF만으로는 EBS 내부 HTML의 실제 요소 구조와 인쇄 미리보기 구현 방식을 확정할 수 없습니다. 따라서 문항 자동 감지는 휴리스틱이며, 도구의 감지 문항 수가 0이거나 실제 출력 결과가 달라지지 않으면 해당 DOM 구조에 맞춘 보정이 추가로 필요합니다.
- 교차 출처 iframe, 별도 브라우저 프로세스, 이미지/캔버스/PDF로 변환된 미리보기 내부는 부모 페이지 스크립트가 수정할 수 없습니다.
- 문항 묶음이 페이지 경계에서 갈라지는 것을 줄이는 대신, 출력 페이지 수가 기존보다 늘어날 수 있습니다.
- `break-inside: avoid`는 문항 블록이 한 페이지보다 긴 경우 완전히 분리되지 않도록 보장하지 않습니다.
- 실제 EBS 로그인 세션에서 v0.2.0을 검증하지 않았습니다. 첨부된 5페이지 PDF는 레이아웃 분석용 입력으로 사용했으며, 자동 감지 성공이나 출력 개선을 검증한 테스트 결과는 아닙니다.

## 테스트
