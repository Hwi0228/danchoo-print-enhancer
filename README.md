# DANCHOO Print Enhancer

중학·고등 EBS DANCHOO+의 기존 시험지 생성·인쇄 흐름을 유지하면서 문항 조판을 보정하는 Tampermonkey 사용자 스크립트입니다.

> 비공식 프로젝트이며 EBS와 제휴·승인되지 않았습니다. 시각 디자인은 국내 수학 문제집의 일반적인 레드 포인트 편집 관습에서 영감을 얻었으며 쎈의 로고·고유 디자인을 복제하지 않습니다.

## v0.3.0

- 문항 번호가 포함된 중첩 요소를 모두 세던 기존 방식 대신, 가장 안쪽의 번호 시작점을 기준으로 탐지합니다.
- 같은 일반 문서 흐름 컨테이너 안에서 번호 시작점 사이의 형제 요소(본문·그림·선택지)를 하나의 문항 그룹으로 묶습니다.
- 그룹에 페이지·단 분할 방지 규칙을 적용합니다.
- 레드 포인트 문항 번호, 얇은 구분선, 정돈된 여백과 본문 타이포그래피를 적용합니다.
- EBS의 자체 인쇄 미리보기와 프린터 설정을 대체하지 않습니다.

## 설치

1. Chrome/Edge에 Tampermonkey를 설치합니다.
2. [사용자 스크립트](danchoo-print-enhancer.user.js)를 엽니다.
3. 스크립트를 설치한 뒤 EBS DANCHOO+의 `solvePaper.ebs` 화면을 새로고침합니다.
4. 도구에서 문항 그룹 구성 수와 번호 시작점 감지 수를 확인합니다.
5. EBS의 기존 인쇄 버튼을 사용합니다.

## 중요 제한

- 현재 그룹화는 같은 일반 흐름 컨테이너 안에서 문항 번호 시작 요소와 다음 문항 시작 요소 사이의 형제 요소를 묶는 휴리스틱입니다.
- 서로 다른 iframe/문서, 서로 다른 컬럼 컨테이너, 캔버스·이미지·PDF로 이미 렌더링된 출력물, 브라우저의 별도 인쇄 미리보기 프로세스는 DOM을 직접 묶을 수 없습니다.
- 2단 편집 컨테이너가 실제로 어떻게 구성되어 있는지에 따라 wrapper 삽입이 적합하지 않을 수 있습니다. flex/grid/table 컨테이너는 의도적으로 건너뜁니다.
- 실제 EBS 로그인 세션의 DOM과 PDF를 확인하지 못했으므로, v0.3.0이 해당 페이지에서 문제 3번을 확실히 묶는다고 보증하지 않습니다. 도구의 그룹 수와 PDF 결과를 함께 검증해야 합니다.
- 문항이 페이지보다 길면 `break-inside: avoid`가 완전한 분할 방지를 보장하지 않습니다. 문항을 통째로 유지하면 페이지 수가 증가할 수 있습니다.
- EBS의 원본 문항 텍스트, 수식, 그림, 정답 데이터를 서버로 전송하지 않습니다.
