# DANCHOO Print Enhancer

중학·고등 EBS DANCHOO+에서 **현재 화면에 표시된 시험지 본문을 더 읽기 좋은 형태로 인쇄**하기 위한 Tampermonkey 사용자 스크립트입니다.

> 비공식 개인용 도구입니다. EBS와 제휴·승인된 프로젝트가 아닙니다.

## 현재 구현 (v0.1.0)

- 인쇄 영역을 사용자가 직접 선택
- 선택한 영역만 인쇄하도록 주변 페이지 UI 임시 숨김
- A4 / A5 / Letter 용지
- 세로 / 가로 방향
- 1단 / 2단 지면 구성
- 글자 크기 및 줄 간격 조절
- 좁게 / 보통 / 넓게 여백 조절
- 설정을 브라우저 로컬 저장소에 저장
- 브라우저 인쇄 대화상자를 통한 프린터 출력 또는 PDF 저장

## 설치

1. Chrome 또는 Edge에 Tampermonkey를 설치합니다.
2. `danchoo-print-enhancer.user.js` 파일을 엽니다.
3. Tampermonkey 설치 화면에서 스크립트를 추가합니다.
4. `https://ai-plus.ebs.co.kr/`에서 DANCHOO+에 로그인하고 시험지를 엽니다.
5. 화면 오른쪽 아래의 **인쇄 영역 선택**을 누른 뒤, 문제들이 들어 있는 가장 바깥쪽 영역을 클릭합니다.
6. 설정을 조정하고 **인쇄 / PDF 저장**을 누릅니다.

## 사용 팁

- 문제 하나가 아니라 **문제 전체를 감싸는 컨테이너**를 선택해야 합니다.
- 처음에는 1단·A4·보통 여백으로 시험 인쇄하는 것을 권장합니다.
- 지문과 여러 문항이 묶여 있는 경우 2단은 읽기 순서가 어색해질 수 있으므로 1단을 우선 사용하세요.
- 수식·그래프가 잘리면 가로 방향 또는 글자 크기 축소를 시도하세요.
- 인쇄 대화상자에서 배경 그래픽 옵션을 켜면 원본의 일부 도형·색상 표현이 더 잘 유지될 수 있습니다.

## 호환성 / 알려진 제한

- v0.1.0은 공식 EBS 페이지의 DOM 구조를 역으로 호출하거나 고정 CSS 선택자에 의존하지 않도록, 사용자가 출력할 영역을 직접 고르는 방식입니다.
- EBS가 문제 본문을 교차 출처 iframe, 별도 팝업, 캔버스 또는 이미지로 렌더링하는 경우에는 선택한 영역만으로 출력되지 않을 수 있습니다.
- 페이지별 분할, 문항 번호 정렬, 정답·해설 분리, 머리말·꼬리말 자동 구성은 아직 구현되지 않았습니다.
- 실제 로그인 세션에서 과목별·학교별 시험지 DOM을 검증하지 못했습니다. 따라서 v0.1.0은 초기 베타이며, 실제 인쇄 화면을 보고 선택자와 페이지 나눔 규칙을 보정해야 합니다.

## 개인정보 및 동작 범위

- 스크립트는 `ai-plus.ebs.co.kr` 페이지에서만 실행됩니다.
- EBS 계정·비밀번호·문항 API·쿠키를 읽거나 전송하지 않습니다.
- 문항을 내려받거나 별도 서버에 저장하지 않습니다.
- 현재 탭에 이미 표시된 DOM에 인쇄용 CSS를 적용하고 브라우저의 `window.print()`를 호출합니다.
- 설정값(용지, 방향, 글자 크기 등)만 브라우저 로컬 저장소에 저장합니다.

## 개발

스크립트 파일 하나로 동작하며 빌드 과정은 필요하지 않습니다.

```bash
node --check danchoo-print-enhancer.user.js
```
